# The Wot Da Shrine guide

Everything a shrine does, a page per part. The [README](../README.md) has the short
version; this is the long one. For how the code is put together, see
[ARCHITECTURE.md](../ARCHITECTURE.md), and for changing it, [CONTRIBUTING.md](../CONTRIBUTING.md).

- [Days without an incident, and the kami](quiet-days.md): the quiet heading, the kami and what it watches, purifying the altar, today's forecast, what the shrine believes
- [A vigil, not a visit](vigils.md): saying something is down and They're back, the shrine's levels, mats and raising a level, rituals
- [Deploys and the watch](deploys-and-the-watch.md): blessing a deploy and the omens, holding the pager

- [Sounds and scenes](sounds-and-scenes.md): what a shrine opens as it grows
- [Features](features.md): everything else, from the offering tray to the keyboard
